## Conclusion

- There is **no NVIDIA GPU and no CUDA toolkit on this machine**; the only
  physical GPU is Intel Arc (out of scope: the codebase has no oneAPI/SYCL
  backend, and none is planned without a separate decision).
- Consequently G0.01 ("CUDA TET4 actual-device build and reference
  acceptance") cannot run here and stays **BLOCKED_ENV** — no CUDA claim in
  this batch is verified, consistent with the README which already states the
  CUDA path is not locally compiled/verified.
- CPU builds never search for CUDA (verified again in this batch's three
  configure runs), so this blocker does not affect any B01 deliverable.

## Unblock condition (user-side)

A host with an NVIDIA GPU (compute capability ≥ 7.0 per `CMAKE_CUDA_ARCHITECTURES 70 80 90`)
and CUDA 12+ toolkit with an MSVC host compiler; then rerun this probe file's
commands plus `G0.01`.
