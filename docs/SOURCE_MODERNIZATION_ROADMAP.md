# Solver Database V2 现代化缺口分析与实施路线

日期：2026-10-23。范围：`solver_database_v2/` 及其外围适配层；不修改生产求解器与其构建拓扑。
目标定位：以当前 V2 架构为基础，建成**更现代化、高效的有限元求解器数据内核**——
单核/多核/GPU 全面对标并力争超越 Abaqus，数据完备性对齐 Abaqus，充分利用现代
CPU（SIMD/缓存/NUMA/混合架构）、GPU（流序内存/异步管线）与存储（压缩/原子 IO）。

本文是规划基线，不是完成声明。所有未验证项遵循仓库规则标注 *not locally verified*。
性能目标为方向性 KPI，须由 P0 基准框架用同机同模型对照实测后修订。

---

## 1. 评价维度与"超越"的定义

| 维度 | Abaqus 参考水平 | V2 目标 |
|---|---|---|
| 单核内核 | 数十年调优的标量/部分向量化内核 | SIMD 批内核 + 混合精度，同模型每步耗时 ≥ Abaqus（≥1.2× 为 P1 目标） |
| 共享内存并行 | SMP 典型 8 核 3–6× | 8T 效率 ≥70%（当前 32%）、32T 效率 ≥50% |
| GPU | 直接解法加速为主，显式 GPU 支持范围有限 | 显式全管线 GPU 常驻；单卡 vs 32 核 CPU ≥5×（以 LS-DYNA GPU 版为业界参照） |
| 分布式 | DMP 数百核扩展（业界参照：强扩展效率 60–80%@16 节点） | 16 节点强扩展效率 ≥60% |
| 数据完备性 | 500+ 单元族、完整材料/约束/荷载/分析类型/ODB | 表 3.5 清单对齐（可表达 + 可求解分层达标） |
| 结果库 | ODB 压缩、out-of-core、GUI 流式读 | 分块 zstd 压缩、稀疏索引、流式增量读 API |
| 可复现性 | DMP 结果存在复现性痛点 | 全路径线程数/分区数无关的逐位确定（已具备设计，须保持） |
| 数据完整性 | ODB 腐败恢复弱 | 指纹+CRC+事务发布（已具备，保持并扩展） |

"超越"的七个现实杠杆：① AoSoA 向量化批内核（对手是标量遗产内核）；② GPU 原生
全管线常驻（对手主要加速直接解法）；③ 持久增量接触搜索（对手每步全量检测）；
④ 受控混合精度（误差可控下用 float 带宽翻倍）；⑤ 确定性并行；⑥ 可验证事务 IO；
⑦ 现代压缩与异步管线。

## 2. 现状资产盘点（路线的地基）

### 2.1 可直接复用的资产

| 资产 | 位置 | 评价 |
|---|---|---|
| 身份链与指纹 | `model.hpp` FNV-1a fingerprint → StateDB/TetPlan/Restart/Result 三重绑定 | 工业级，扩展到分区/多卡时保持"身份先于数据" |
| SoA/AoSoA 布局机制 | `field.hpp` | AoSoA 已有定义但**无内核使用**（P1 的接缝已预留） |
| 冻结模型 + 双连接表 | `model.hpp` CSR + 批次 SoA | 批次不含 part 维度、无高阶/壳/梁谱系（P2 扩展点） |
| 状态事务 | `state.hpp` trial/commit/rollback | `begin_trial` 整份拷贝需改增量（P6 前置） |
| 确定性装配 | `dynamics.hpp` 邻接序 gather，逐位一致 | 保持为默认，Atomic 为可选 |
| 隐式数据契约 | `implicit.hpp` DofMap/CSR/BSR/matrix-free | 无求解器、无消去树/填充 schema（P6） |
| 接触身份池 | `contact.hpp` generation/有界候选 | 检测/本构在 general_contact |
| 通用接触参考内核 | `general_contact/` 12 头：BVH、NTS、罚+库仑、客观摩擦、AD 一致切线、CoupledTrial | 每次求值全量重建 BVH、单点积分、无 mortar/CCD（P3） |
| CUDA 内存/镜像 | `cuda_memory.hpp` 流序池、pinned、五态 Residency | 设计领先；仅单卡、仅 TET4、未本地编译（P5） |
| lifecycle 全链 | INP 子集→IR→编译→结果→VTK/XDMF→重启 | 无 DLOAD/MPC/NLGEOM；解析子集窄（P2） |
| IO 基元 | `io/native.hpp` 分块 CRC、原子写、visit 序列化 | 无压缩、无并行 IO、索引起始全扫（P7） |
| 验证文化 | 验收文档 + 契约测试 + not-verified 标注纪律 | 保持并升级为 CI 性能回归（P0） |

### 2.2 实测性能基线（2026-10-22，Ultra 9 285H，1M 节点/333k TET4）

- 显式 10 步热路径：4T float 2.49×（效率 62%）、8T float 2.58×（**效率 32%**）；
  double 4T 1.88×、8T 2.59×。
- float 节点循环 8T **回退**（8.90→14.88ms）：混合 P/E 核 + `schedule(static)` + 无亲和性。
- 端到端仅 1.3–1.5×：`finalize`/`TetPlan`/分配等串行段占 >80% 时间占比被锁死。
- IP 历史场 8 分量流式 8T 达 **5.22×**：证明计算/字节比是当前第一杠杆。
- View 路径 float/4 比裸数组慢 ~36%（`gather_view_raw_ratio 1.36`）：抽象层开销未还清。
- 接触逐条原子追加 4T **负加速**（0.24×），批量追加修复为比串行快 3.8×。
- 无 >8T、无 general_contact 加速比、无任何 GPU 实测数据。

## 3. 系统缺口分析（按层）

### 3.1 单核：内核与缓存（L1）

| # | 缺口 | 现状锚点 | 对标差距 |
|---|---|---|---|
| S1 | 无 SIMD 向量化内核 | `dynamics.hpp tet_force` 标量 per-element；AoSoA 无人用 | Abaqus 内核历经手工向量化；现代 AVX2/AVX-512 批处理可 4–8× 于标量 |
| S2 | 抽象层开销未清零 | float/4 View 比 raw 慢 36% | raw 对齐是最低要求 |
| S3 | 无缓存分块调度 | 批次按 (topo,mat,ips) 分组，无节点局部性 tile | gather 的 L2 命中率决定显式内核上限 |
| S4 | 无混合精度策略 | 模板 T 二选一，全 float 或全 double | Abaqus/Explicit 默认单精度+关键路径双精度；现代做法是分级精度+误差监控 |
| S5 | 无大页/TLB 优化 | `AlignedAllocator` 常规 4KB 页 | 1M+ 节点模型 TLB miss 显著 |
| S6 | 稳定步长界过保守 | `0.25/(‖B‖√((λ+2μ)/ρ))`，0.8 系数再折减 | 直接吃掉 25% 步数效率 |
| S7 | 串行建模/计划段 | `finalize`、`TetPlan`、指纹全单线程 | 端到端被锁死在 1.5× |

### 3.2 多核：共享内存并行（L2）

| # | 缺口 | 现状锚点 | 差距 |
|---|---|---|---|
| M1 | 无 CPU 拓扑感知 | 无亲和性；静态调度对 P/E 核失衡 | float/8 回退的直接根因 |
| M2 | 无 NUMA first-touch | `LAYOUT_AND_SYNC.md` 自述未实现 | 双路服务器带宽减半级 |
| M3 | OpenMP static 单策略 | `parallel_for` 仅 static | 接触等不规则负载需 task/guided |
| M4 | 端到端串行段未并行化 | 见 S7 | Amdahl 上限 |
| M5 | 确定性约束下的装配 | 已有 gather/atomic 双路 | 需保持逐位一致并扩展到接触/隐式归约 |
| M6 | 无 >8T 数据 | 基准仅 1/4/8 | 目标机器 16–64T 未测 |

### 3.3 GPU（L3）

| # | 缺口 | 现状锚点 | 差距 |
|---|---|---|---|
| G1 | CUDA 未编译验证 | `cuda_configure.txt` nvcc 缺失 | 一切 GPU 目标的前置 |
| G2 | 单元族仅 TET4 | `cuda_backend.cu` 三 kernel | HEX8R/壳/梁 GPU 内核全缺 |
| G3 | 接触只有数据通道 | `cuda_contact.hpp` 候选/manifold 往返 | 检测（GPU LBVH/排序）与力 kernel 缺 |
| G4 | 无时变外载/接触力更新通路 | external/contact 镜像设备端只读 | 全管线常驻的断点 |
| G5 | 单卡、单流、单进程 | Context 单设备 | 多卡分解、跨卡通信、与 MPI 混合缺 |
| G6 | download 覆盖语义粗糙 | snapshot 整体覆盖 target | 需分场选择性回传 |
| G7 | 无 GPU 侧性能剖析 | event 计时口径含空转 | 需 nsight 级 profile 基线 |

### 3.4 分布式（L4）——最大结构性缺口

| # | 缺口 | 说明 |
|---|---|---|
| D1 | 无分区所有权模型 | `MIGRATION.md` 明言 no fake placeholder；需图分区（METIS/KaHIP 适配）+ owned/ghost 语义 |
| D2 | 无幽灵交换协议 | 节点/DOF/单元三层 halo、通信计算重叠 |
| D3 | 接触跨分区 | 跨域面对去重、全局候选归并、ghost 面片缓存 |
| D4 | 全局归约 | 稳定 dt、能量、收敛范数的可扩展实现 |
| D5 | 并行 IO | 分布式结果分片/合并、分布式检查点 |
| D6 | 确定性 DMP | 保持"分区数无关逐位一致"是其差异化，需在通信序上设计 |

### 3.5 数据完备性（L5）——对标 Abaqus 的清单

**单元族**（现仅 7 拓扑枚举 + C3D4 内核）：
- 实体：C3D8/C3D8R(+沙漏场)/C3D8I、C3D10/C3D10T、C3D20/C3D20R、无限元
- 壳：S3/S4/S4R/S4RS、S8R、SC6R/SC8R 实体壳、膜 M3D4
- 梁：B31/B32（截面方向场、截面积分声明——现"显式未知"）
- 其它：刚体（离散/解析面）、弹簧/阻尼/连接器、cohesive COH3D8、热-力耦合 C3D8T、声学
- 每族需要：节点/边/面数表、IP 布局、面朝向表、退化处理、输出位置（`Location` 已预留 SectionPoint/Face/Contact 无 publisher）

**材料库**（现 model=1 各向同性线弹性）：
- 弹性：各向异性/正交/短纤维/超弹（Ogden/Neo-Hooke/Yeoh/Arruda-Boyce）/低弹
- 塑性：Mises/Hill/Drucker-Prager/Mohr-Coulomb/Cam-clay/泡沫/铸铁
- 损伤与失效：ductile/Johnson-Cook/Hashin/cohesive damage
- 率相关/温度相关/粘弹/蠕变；复合材料铺层
- **用户本构插件接口**（UMAT/VUMAT 等价物：参数包+历史布局+切线类型契约）
- 历史变量 schema 注册/迁移机制（现仅数量，无 per-schema 打包/恢复/输出声明）

**约束**（现仅 SPC −1 消去）：MPC/CEQ 装配、RBE2/RBE3 等价、tie/bonded、coupling、embedded、壳-实体连接。

**荷载**（现仅 CLOAD+幅值）：**DLOAD 全族**（压力/重力/离心/静水压/管道压力）、分布面/边荷载、热载荷、**随动荷载**（NLGEOM 必需）、`loads()` 每增量清零重加需改增量更新。

**分析类型**（现仅常步长显式）：质量缩放/体积粘性/子循环（显式效率三大件）、NLGEOM（当前构形梯度+客观率+转动更新）、隐式 Newton/HHT-α、线性静力、特征值（Lanczos/AMS）、模态叠加/谐响应/随机、热分析。

**接触**（现 NTS 参考内核）：STS/mortar（非匹配网格 patch test）、边-边自动检测、特征边识别、全域 CCD、壳厚偏置、解析刚体面、软ening/黏附、热接触、tie 转换。

**结果**（现 U/V/A/RF/S/E/ALLKE/ALLSE）：ALLIE/ALLWK/ETOTAL 能量审计、截面/截面点输出、接触量输出、历史高频通道、跨网格映射。

### 3.6 IO 与持久化（L6）

- 无压缩（ODB 有）；结果同步写单帧在途；帧索引起始全扫 O(file)；帧索引常驻内存随帧数线性；
  无 out-of-core/mmap；无并行写；检查点 v2 兼容路径整体驻留（v3 已分块）。

### 3.7 验证与工程（L7）

- 无与 Abaqus 的同模型对照框架（一切"对标"无实测依据）；无 CI/性能回归门禁；
  Linux/CUDA 未跑；无 TSan；无真实工业负载回归语料（现仅合成网格+解析振子）。

## 4. 目标架构蓝图

在现分层上新增六个横切服务，全部以适配器/接口层形式加在既有接缝上，不推翻现有设计：

```
┌────────────────────────────────────────────────────────────┐
│ 应用层: lifecycle / sdb_run / 生产适配器(FNL/FEG 导出)        │
├────────────────────────────────────────────────────────────┤
│ 求解编排: CpuRun / GpuRun / MpiRun(新)   分析类型驱动器(新)    │
├───────────────┬──────────────┬───────────────────────────────┤
│ 单元内核层(扩)  │ 接触引擎(扩)  │ 隐式层(新): 装配/约束变换/求解器适配 │
│  SIMD 批内核   │  持久增量搜索 │  (MKL PARDISO/MUMPS 适配先行)    │
│  材料插件接口   │  mortar/CCD  │  消去树/填充/预因子 schema       │
├───────────────┴──────────────┴───────────────────────────────┤
│ 数据内核(现): Field/SoA/AoSoA · MeshDB(扩谱系) · StateDB(增trial)│
│              · ContactDB · ImplicitExtension · 指纹身份链       │
├────────────────────────────────────────────────────────────┤
│ 横切服务(新):                                                  │
│  · 拓扑服务(topology): 检测 CPU/NUMA/P-E 核, 亲和性, 线程池       │
│  · 精度服务(precision): 分级精度策略+误差监控                    │
│  · 分区服务(partition): 图分区适配, owned/ghost, halo 交换        │
│  · GPU 运行时(扩): 多卡, GPU 接触, 异步管线                     │
│  · IO 服务(扩): zstd 分块压缩, 并行写, 稀疏索引, 流式读          │
│  · 验证服务(verify): patch/MMS/回归语料 + Abaqus 对照基准         │
└────────────────────────────────────────────────────────────┘
```

关键设计决策：
1. **SIMD 抽象层**：以 `std::experimental::simd`/手写 intrinsic dispatch 隐藏 AVX2/AVX-512/NEON；批内核以 AoSoA<W> 为一等布局（W=寄存器宽度），保持 CPU/GPU 同源公式（延续 `tet_force` SDB_HD 模式）。
2. **内核分层**：公式层（共享、纯函数、可 AD）→ 批处理层（SIMD/缓存块）→ 调度层（tile/着色/task）。
3. **求解器后端适配先行**：隐式先接 MKL PARDISO/MUMPS（生产仓库已有依赖先例），自研直接解法后置；V2 只负责稀疏模式/符号分解缓存/切线事务。
4. **材料插件 ABI**：数值 model ID → 注册表（参数包 schema + 历史 layout + 切线种类），保持 checkpoint 自描述。
5. **确定性契约全局保持**：任何新并行路径（GPU/MPI）必须给出"同输入同构建逐位一致"或显式声明的容差策略。
6. **分区感知从数据内核做起**：Field 增加 rank 所有权注记（可选装饰，不改变单机布局），ghost 交换是显式阶段屏障（延续阶段所有权协议）。

## 5. 实施路线（P0–P7）

每阶段给出：目标 / 工作项（含现状锚点）/ 出口准则 / 风险。顺序即推荐优先级；
P1/P2 可部分并行，P3 依赖 P1 的调度层，P4/P5 可并行，P6 依赖 P2 约束层。

### P0 — 基准与工程地基（先于一切优化）

目标：让"对标"可测量、让机器特性可利用。
- P0.1 Abaqus 对照基准框架：选定 3–5 个参考模型（纯 HEX8R 弹性波传播、壳+实体跌落、
  接触为主板件冲击），指标 = 每步耗时/DOF、内存/DOF、写盘带宽；产出对照表机制。
- P0.2 CPU 拓扑服务：检测核型/NUMA 域；线程亲和 API；P/E 核分组调度策略。
- P0.3 分配器增强：NUMA first-touch、2MB 大页可选。
- P0.4 串行段并行化：`finalize`/`TetPlan`/指纹并行（端到端解锁）。
- P0.5 CI：构建+契约测试+性能回归门禁（对本机基准 JSON 做阈值比对）。
出口：float/8 节点循环不再回退；端到端 8T ≥2×；对照框架出第一份 Abaqus 数据。
风险：Abaqus 许可/环境不可得 → 以公开基准（如 LS-DYNA 示例模型换算）替代并降级目标表述。

### P1 — 单核现代化（超越的第一战场）

- P1.1 SIMD 抽象层 + AoSoA 批内核基座（复用 `field.hpp` AoSoA，W 按目标机选择）。
- P1.2 TET4 内核向量化重写（作为验证载体）；HEX8/HEX8R 紧随（工业主力）。
- P1.3 缓存分块 tile 调度：按节点局部性重排批次处理序，gather L2 命中率纳入基准。
- P1.4 View 开销清零：布局特化+强制内联，重跑 raw 对照（当前 1.36× 比值 → ≤1.05×）。
- P1.5 混合精度：单元内力 float、装配累加/时间 double 的分级策略+误差监控开关。
- P1.6 稳定步长界精化（单元族特征值估计替代全局保守界，预留用户覆盖）。
出口：HEX8R 模型单核每步耗时 ≥ Abaqus/Explicit（P0 框架实测）；IP 类负载 8T 效率 ≥60%。
风险：向量化与逐位确定性冲突 → 确定性定义为"同 SIMD 宽度内一致"，跨宽度声明容差。

### P2 — 数据完备性（对标 Abaqus 的主体工程，最大工作量）

- P2.1 单元族谱系框架：Topology→族 traits 表（节点/边/面/IP/朝向/退化），`ElementDescriptor`
  从"语义侧车"升级为内核驱动数据；批次键扩展（含截面/公式变体）。
- P2.2 截面与复合材料：solid/shell/beam/membrane section schema + 铺层。
- P2.3 材料库与插件：注册表 + 参数/历史 schema + 切线种类；UMAT 式插件接口（进程内 ABI）；
  优先实现：Mises 塑性、超弹 Ogden、Johnson-Cook、损伤。
- P2.4 荷载系统：DLOAD 全族 + 随动荷载 + 热载荷；`loads()` 改增量更新。
- P2.5 约束装配器：MPC/CEQ（显式罚/传递，隐式变换/消去双路）、RBE2/3、tie、embedded。
- P2.6 NLGEOM：当前构形梯度通路、客观应力更新、壳大转动、随动荷载激活。
- P2.7 显式三大件：质量缩放（全局/局部/目标 dt）、体积粘性、子循环（先数据通路后调度）。
- P2.8 内核实现顺序：HEX8R+沙漏 → S4R 族 → TET10 → B31 → C3D20R → cohesive/耦合。
- P2.9 INP 解析器扩到对应关键词（*DLOAD/*PLASTIC/*MPC/*TIE/*SURFACE INTERACTION…）。
出口：可表达并求解 P0 参考模型全集（壳+实体+tied 接触跌落），数据完备性清单 ≥80%。
风险：范围失控 → 每族以"参考算例+解析/收敛测试"定义完成，不做无验收的铺量。

### P3 — 接触现代化（效率与完备双目标）

- P3.1 持久增量 BVH：树跨步保留、运动更新、并行重建（LBVH 式）替代每步全量重建。
- P3.2mortar/STS 离散可选（非匹配网格 patch test 达标）；积分面积随变形更新。
- P3.3 特征边自动识别 + 边-边全域检测（圆角边机制泛化）；顶点特征。
- P3.4 全域 CCD（对接已有 `sweep_static_triangle`，进时间步控制）。
- P3.5 GPU 检测管线：GPU 候选生成 + 排序去重 + 有界回传（接 `cuda::Candidates`）。
- P3.6 接触完备语义：软ening/黏附、热接触、接触能量审计输出。
出口：百万接触对模型接触段耗时占比与 Abaqus 对照；非匹配网格 patch test 通过。
风险：mortar 线性化复杂 → 先罚式 STS 后 mortar。

### P4 — 分布式并行（规模对标的关键）

- P4.1 分区服务：METIS/KaHIP 适配（工具目录独立库），owned/ghost 数据结构装饰进 Field/MeshDB。
- P4.2 halo 交换：节点/DOF 两层，通信-计算重叠（非阻塞 send/recv + 装配分段）。
- P4.3 接触跨分区：ghost 面片缓存、跨域候选仲裁（确定性归并序）。
- P4.4 全局归约与全局稳定 dt；分区负载均衡（含质量缩放下的分区再平衡）。
- P4.5 并行 IO：结果分片+合并视图、分布式检查点（写谁拥有）。
出口：参考模型 16 节点强扩展效率 ≥60%（对照框架）。
风险：逐位确定性 vs 通信序 → 设计"固定归并序"协议并在验收中专项测试。

### P5 — GPU 原生全管线（超越的主战场）

- P5.0 前置：修 CUDA 工具链（MSVC 宿主或 Linux），补齐现有测试的设备验证。
- P5.1 多卡执行：卡间分解复用 P4 分区服务；NVLink/SHARP 感知（可选）。
- P5.2 单元内核 GPU 化：HEX8R/壳/梁（延续同源公式层）；GPU 材料插件编译通路。
- P5.3 接触 GPU 求解：检测（P3.5）+ 力 kernel + manifold 更新，全常驻。
- P5.4 异步管线：单元力/接触/积分/IO 的流级重叠；选择性 download（修 G6）。
- P5.5 混合精度 GPU：FP32 主通路+FP64 关键归约，误差监控。
出口：全模型（非振子）单卡 vs 32 核 CPU ≥5×；GPU/CPU 一致性容差策略成文。
风险：显存容量 → 常驻集预算工具+分块驻留降级模式。

### P6 — 隐式与求解器层

- P6.1 trial 增量化：去掉整份 StateData 拷贝（脏场标记+按场恢复）。
- P6.2 稀疏模式服务：消去树/填充估计/符号分解缓存（接后端）。
- P6.3 求解器适配：MKL PARDISO/MUMPS 后端 + 收敛控制 + 线搜索/弧长。
- P6.4 MPC/CEQ 进隐式（变换法）；HHT-α 隐式动力学；特征值（Lanczos 后端）+模态数据通路。
出口：线性静力/非线性准静态/模态基准 vs Abaqus/Standard（P0 框架扩 implicit 模型）。
风险：后端许可 → MUMPS(公共) 保底。

### P7 — 结果库现代化（对标/超越 ODB）

- P7.1 分块 zstd 压缩（保持 CRC 事务语义）；字段级压缩率/速度档位。
- P7.2 稀疏帧索引 + mmap/out-of-core 读；流式增量读 API（GUI 友好）。
- P7.3 并行写（P4.5 的单机版：多线程压缩流水）。
- P7.4 能量审计全家（ALLIE/ALLWK/ETOTAL）、截面输出、接触输出 publisher。
- P7.5 跨网格结果映射（重启换网格）。
出口：同模型结果文件体积/读写带宽 vs ODB 对照；GUI 原型可流式刷帧。

## 8. 风险登记（Top）

1. **范围失控**（P2 单元/材料谱系是十年量级工程）→ 以参考算例定义"完成"，垂直薄片滚动。
2. **确定性 vs 性能**（SIMD 宽度、通信序、GPU 归约）→ 分级承诺：进程内逐位、跨拓扑容差，写入契约文档。
3. **外部依赖**（METIS/KaHIP/MUMPS/zstd/Abaqus 对照环境）→ 全部以适配器隔离，公共许可保底。
4. **GPU 生态**（本机无 nvcc）→ P5.0 前置专门解决工具链，否则 P5 冻结。
5. **与生产求解器关系**（AGENTS.md 约束）→ 本路线全部限于 solver_database_v2/ 与 tools/；
   生产接入永远走导出器/适配层，不反向修改旧代码。
