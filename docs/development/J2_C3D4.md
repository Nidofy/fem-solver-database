# Small-strain J2 material on CPU C3D4

The solve reader combines positive density, isotropic elasticity and a model-level
`*PLASTIC` card (optional `HARDENING=ISOTROPIC`). Each row gives yield stress
and equivalent plastic strain. The first strain must be zero. Subsequent strains
increase strictly and stresses are positive and nondecreasing. Both input values
and the selected precision are checked. Stress interpolates linearly between knots
and stays constant after the last knot. A single row gives perfect plasticity.
See the [Abaqus material data conventions](https://docs.software.vt.edu/abaqusv2025/English/SIMACAEMATRefMap/simamat-c-materialdata.htm).

## State and internal force

ModelIR schema 5 carries the named curves. ModelStore reconstructs J2 material
0x4a320001 with parameters rho, E, nu, followed by the row pairs. The persistent
history schema sdb.j2.isotropic version 1 allocates six tensor plastic strains
(XX, YY, ZZ, XY, YZ, ZX) and scalar PEEQ per IP. Their initial values are zero.
Schema 1 through 4 retain their wire layouts. Mesh-only INP import preserves the
plastic card as opaque. Reimport the source in solve mode for executable physics.

Given total strain and committed plastic strain, form the elastic trial stress,
its deviator s and q = sqrt(3/2 s:s). The scalar return solves
q - 3 G dp = yield(PEEQ + dp) on the applicable table segment. The tensor flow
increment is (3/2) dp s/q. The trial returns stress, history and recoverable
elastic energy density. Hydrostatic loading produces no plastic flow. The
stability bound uses the elastic wave speed.

The standalone CPU plan assembles corrected stress into element force. It stages
the accepted endpoint strains using the central difference nodal update, then
commits all plastic points at the time of the new displacement. Initialization
commits initial displacements. Stress and force scratch follow the existing
staggered explicit timing. Current-time publication evaluates from displacement
and committed history, without advancing it. State trials support rollback.
PEEQ output selects plastic elements in the requested region. ALLSE integrates
one half stress contracted with elastic strain, excluding plastic work.

## Numerical checks and migration

The material-point reference with E=200, nu=0 and a yield curve from (2,0)
to (3,0.01) produces PEEQ=0.005 and axial stress 3 at constrained axial
strain 0.02. Elastic unloading to 0.015 gives stress 2 at unchanged PEEQ.
Reverse loading crosses the last knot. Tests check positive plastic work,
hydrostatic loading and pure shear at yield stress divided by sqrt(3).

The forced j2_tet.inp fixture checks first yield, independent points, current
PEEQ, elastic energy, model reload and checkpoint continuation in both precisions.
The process pipeline checks legacy/indexed result files, asynchronous output,
restart append and VTK export. Reproduce with the j2_contracts and
lifecycle_process_pipeline CTest targets. Windows GCC 15.2 lifecycle regression
passed 78,323 checks. The focused J2 trajectory also ran under Windows MSVC
19.51 ASan and WSL GCC 13.3 ASan/UBSan (Index64). The mixed-IP foundation
and separate-process reader passed 171 and 3 checks. DBF5 consumer regression
passed 178,781 checks. A separate reviewer rechecked mesh-only preservation,
the accepted time level of history, and input validation before FP32 narrowing.

Legacy MaterialData stores a plastic curve reference and a plastic modulus.
Resolve the table and its units at migration. Confirm that its abscissa is
equivalent plastic strain before import. This batch supports C3D4, fixed
reference gradients and rate-independent isotropic hardening. Other J2 element
families and the elastic reference consumer reject execution. Temperature,
kinematic hardening, softening, finite rotations, plastic dissipation output
and GPU execution remain outside this contract. Industrial comparisons and
formal dual-review acceptance are pending.
