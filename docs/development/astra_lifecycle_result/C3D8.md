# C3D8 CPU formulation contract

Scope: small displacement gradients, isotropic linear elasticity, full 2x2x2
Gauss quadrature, constant-step central difference. This is not a finite-rotation
objective formulation. C3D8R remains non-executable. CUDA remains TET4 only.

Node signs (xi,eta,zeta): 1---, 2+--, 3++-, 4-+-, 5--+, 6+-+, 7+++, 8-++.
N_a = (1+s_x xi)(1+s_y eta)(1+s_z zeta)/8. J_ij=dx_i/dxi_j;
grad_x N = J^-T grad_xi N. All eight Gauss weights are one at +/-1/sqrt(3).
IP order is binary xi-fastest, then eta, then zeta: ---,+--,-+-,++-,--+,+-+,-++,+++.
Face membership follows existing abaqus_face; no parser-only execution aliases.

strain=sym(grad u), stress=lambda tr(strain) I+2 mu strain; tensor shear storage.
Internal force sums grad(N)^T stress det(J) over the 8 points. Lumped mass is
rho sum_q N_a(q) det(J_q), i.e. the row sum of the consistent quadrature mass.
Geometry/material must be finite, determinant positive at every quadrature point,
and lumped mass positive. No claim of exhaustive validity between sample points.

Stability: assemble a temporary 24x24 element stiffness during plan construction.
L_e=max_i sum_j |K_e(i,j)|/m_e(i). Positivity of row-sum masses gives a global
Gershgorin bound lambda_max(M^-1 K)<=max_e L_e even with shared nodes. Use
0.95*2/sqrt(max_e L_e); existing TET4 bound stays unchanged. No dense K is retained.

Reference shape-function family: [Altair theory manual](https://help.altair.com/hwsolvers/rad/topics/solvers/rad/theory_element_linear_brick_shape_functions_r.htm)
(the manual uses a different axis/node permutation; the signs above are normative).
Full integration scope: [CalculiX author manual](https://www.feacluster.com/CalculiX/ccx_2.18/doc/ccx/node28.html).
Tests use independent exact polynomial integrals on the unit cube, not external
commercial-solver runs. No Abaqus comparison is claimed.

Result contract: one field per (name, region, history, IP, section point), using
existing ResultDescriptor integration_point. IP1 includes TET4 and HEX8; IP2..8
include HEX8 only. Reader field/entity_field and history accept an optional point
(default 1); CLI --ip selects it. Export S/E are IP1, S@IP2..S@IP8 and E@IP2..E@IP8
are separate cell arrays; missing TET4 points are NaN in dense visualization only.
No element averaging is substituted for integration-point data. StateDB already
stores packed variable IP counts; restart preserves all points without a schema
change. Hex configuration identity differs from the legacy TET4 configuration.

Verification: float/double analytic polynomial stiffness; eight-point affine
patch and stress; total/mixed mass and force equilibrium; infinitesimal rigid
modes; deterministic and atomic OpenMP; invalid/zero Jacobian; oscillator time
convergence and axial-bar mesh convergence; INP mixed offsets, eight-point
history, exports and exact split restart. Tolerances: mechanical patch/force
2e-5 float and 1e-12 double; deterministic serial/OpenMP and split states are
bit-identical. Nonlinear/finitely rotated problems remain outside scope.
